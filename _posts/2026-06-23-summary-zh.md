## [提示注入被重新定义为角色混淆](https://role-confusion.github.io/) ⭐️ 8.0/10

一篇新论文将提示注入攻击重新定义为角色混淆，即大语言模型无法区分系统角色和用户角色，并表明尽管基准测试得分很高，人类红队成员仍能实现接近 100%的攻击成功率。 这种重新定义提供了对提示注入为何有效的更深入理解，能够催生新的攻击向量和更好的防御措施，并凸显了静态基准测试在衡量大语言模型安全性方面的不足。 该论文已被 ICML 2026 接收，表明角色混淆解释了为何即使模型在标准基准测试中得分完美，攻击仍能成功，并指出像为角色边界设置特殊 token 这样的 token 级防御可能不够充分。

hackernews · x312 · Jun 22, 15:48 · [社区讨论](https://news.ycombinator.com/item?id=48631888)

**背景**: 提示注入是一种网络安全利用手段，通过绕过安全防护使大语言模型产生意外行为。传统防御包括系统提示和 token 级标记，但这项研究表明，核心漏洞在于模型无法维持角色区分。

## [Claude Code 的扩展思考输出是有损摘要](https://patrickmccanna.net/the-text-in-claude-codes-extended-thinking-output-is-not-authentic/) ⭐️ 8.0/10

一项分析揭示，Claude Code 的“扩展思考”输出是模型实际推理过程的有损摘要，而非真实的思维链。这意味着用户看到的是压缩版本，可能遗漏关键细节，并且可以被操纵。 这削弱了 AI 透明度和信任，因为用户无法验证模型的真实推理过程。同时带来了安全风险，例如隐藏的提示注入攻击可以在不被察觉的情况下改变推理内容。 这种有损摘要类似于将无损的 BMP 转换为有损的 JPEG，导致数据丢失。隐藏的推理过程可能被用于提示注入攻击，攻击者的指令在隐藏链中执行，而摘要无法揭示这种操纵。

hackernews · 0o_MrPatrick_o0 · Jun 22, 14:22 · [社区讨论](https://news.ycombinator.com/item?id=48630535)

**背景**: 像 Claude 这样的大型语言模型通常使用思维链推理来提高准确性。公司可能隐藏完整的推理过程以保护专有技术，或防止竞争对手在其思维链上进行训练。然而，这种做法引发了关于问责制和安全的担忧。
