## [GrapheneOS Protects Locked Devices from Data Extraction](https://discuss.grapheneos.org/d/40700-grapheneos-protections-against-data-extraction-from-locked-devices) ⭐️ 8.0/10

A community discussion highlights GrapheneOS's robust protections against data extraction from locked devices, including an auto-reboot feature that returns the device to Before First Unlock (BFU) mode after a configurable period of inactivity. These protections are critical for journalists, activists, and anyone facing physical device seizure, as they prevent forensic data extraction even without a duress PIN. GrapheneOS sets a new standard for mobile security by building on Android 17 and Pixel hardware security features. The auto-reboot timer can be set as low as 4 hours, ensuring that after the device reboots, all encryption keys are fully encrypted and inaccessible. GrapheneOS also disables USB-C at a hardware level to prevent attacks via USB connections.

hackernews · Cider9986 · Jul 26, 05:57 · [Discussion](https://news.ycombinator.com/item?id=49055169)

**Background**: Before First Unlock (BFU) mode is a state where the device's encryption keys are not loaded into memory, making data extraction impossible. Standard Android devices may leave keys in memory after unlock, but GrapheneOS's auto-reboot forces the device back into BFU mode periodically, enhancing security against physical attacks.

This change causes many existing CI pipelines to fail due to newly flagged violations. This major default rule expansion significantly improves code quality by catching severe issues like syntax errors and runtime errors without requiring any configuration. Python developers must update their codebases or pin Ruff versions to avoid CI breakage. Ruff now has 968 total rules, up from 708 in v0.1.0, and the new defaults include rules like DTZ005 (timezone-aware datetime), BLE001 (blind exception catch), and B018 (useless attribute access). The default rule set had not been updated since Ruff v0.1.0 in October 2023.

## [Microsoft to Use TPM Chips to Block Pirated Windows Activation](https://www.techspot.com/news/113232-microsoft-using-tpm-chips-crack-down-pirated-windows.html) ⭐️ 8.0/10

Microsoft announced it will add TPM-based hardware verification to its KMS (Key Management Service) for enterprise volume activation, requiring KMS servers to prove their hardware identity is Microsoft-certified and unaltered before processing activation requests. This feature will become mandatory starting with the next Windows Server release and will be pushed as a readiness notification in Windows Server 2025 from August 2026. This move directly targets the widespread piracy method of using fake KMS servers, which has been a primary tool for unauthorized Windows activation for years. If effective, it could significantly disrupt the ecosystem of pirated Windows activations, though the ongoing cat-and-mouse dynamic with tools like TSforge suggests the battle is far from over. The TPM attestation process involves three steps: verifying the KMS host's identity, checking for code tampering, and only then allowing activation requests. Microsoft previously blocked the KMS38 exploit in 2025, and the new TPM requirement is expected to render Online KMS tools (which require periodic reconnection to fake servers) obsolete.

telegram · zaihuapd · Jul 25, 15:55

**Background**: KMS (Key Management Service) is a Microsoft technology for volume activation of Windows and Office within an enterprise network. It allows organizations to activate multiple machines using a local KMS server instead of contacting Microsoft directly. Pirated activation tools have long exploited this by setting up fake KMS servers that mimic legitimate ones. TPM (Trusted Platform Module) is a hardware security chip that can generate cryptographic keys and attest to system integrity.

Decker is a modern reincarnation of HyperCard that uses 1-bit graphics and aims to recreate the intuitive, self-contained application experience for a new generation. It builds on the legacy of HyperCard and classic macOS, offering a platform for creating interactive stacks. This project revives a pioneering hypermedia paradigm that empowered non-programmers to create rich applications, potentially inspiring a new wave of accessible authoring tools. It also taps into nostalgia and retrocomputing interest, while its 1-bit graphics make it suitable for e-ink devices. Decker uses 1-bit graphics, meaning each pixel is either black or white, which gives it a distinctive retro aesthetic and makes it efficient for e-ink displays. It is designed to be self-contained, allowing users to build and share interactive stacks without external dependencies.

**Background**: HyperCard was a software application and development kit for Apple Macintosh, released in 1987, that combined a flat-file database with a graphical, user-modifiable interface and a built-in scripting language called HyperTalk. It allowed users to create interactive multimedia projects, known as stacks, and was widely used for rapid application development, databases, and educational software. HyperCard was discontinued in 2004, but its influence persists in modern hypermedia and visual programming tools.

French firefighters faced pyrocumulonimbus clouds for the first time as massive wildfires in the Bordeaux region forced the evacuation of 200,000 people and destroyed hundreds of homes. This marks the first occurrence of pyrocumulonimbus in France, signaling that climate change is intensifying wildfire behavior in regions not previously prone to such extreme fire-generated weather, posing new challenges for firefighting and public safety. Pyrocumulonimbus clouds can generate lightning, extreme winds, and even tornadoes, which can dramatically increase fire spread and create dangerous conditions on the ground. The fires are fueled by artificial pine monocultures planted in the 19th century, which are highly flammable due to resin and needle litter.

**Background**: Pyrocumulonimbus (PyroCb) is a type of cumulonimbus cloud that forms above intense heat sources like wildfires, capable of reaching the upper troposphere or lower stratosphere. It was first documented in 1998 and can inject smoke into the stratosphere, affecting climate. The Landes and Médoc forests are artificial pine monocultures created under Napoleon III to drain wetlands, and their continuous canopy and flammable litter make them especially fire-prone.
