## [OpenAI Model Disproves Erdős Conjecture in Discrete Geometry](https://openai.com/index/model-disproves-discrete-geometry-conjecture/) ⭐️ 9.0/10

An OpenAI model has disproved the Erdős distinct distances problem, a central conjecture in discrete geometry that had stood for 80 years, by constructing a counterexample using algebraic number theory. This marks a milestone in AI-driven mathematics, demonstrating that AI can independently solve long-standing open problems and potentially accelerate discovery in pure mathematics. The model found a counterexample showing that for infinitely many values of n, the maximum number of unit distances among n points exceeds a linear growth rate by a fixed positive constant, disproving the conjecture. The proof was formalized in the Lean theorem prover.

hackernews · tedsanders · May 20, 19:05 · [Discussion](https://news.ycombinator.com/item?id=48212493)

**Background**: The Erdős distinct distances problem asks for the minimum number of distinct distances determined by n points in the plane. Paul Erdős conjectured in 1946 that the number is nearly linear in n. The problem was a central open question in discrete geometry until the current best lower bound was established by Guth and Katz in 2015.

## [Mozilla Deprecates asm.js, Marks End of an Era](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html) ⭐️ 8.0/10

Mozilla announced the deprecation of asm.js, a JavaScript subset that enabled near-native performance in the browser, as WebAssembly has become the standard for high-performance web applications. This marks the end of a foundational web technology that paved the way for WebAssembly and enabled early high-performance web apps like Figma. Developers should migrate any remaining asm.js code to WebAssembly for better performance and future compatibility. asm.js was a strict subset of JavaScript that allowed ahead-of-time optimization, but it required parsing as JavaScript, leading to larger bundle sizes and slower load times compared to WebAssembly's binary format. Mozilla's Firefox was the first browser to implement asm.js optimizations in version 22.

hackernews · eqrion · May 20, 12:01 · [Discussion](https://news.ycombinator.com/item?id=48206340)

**Background**: asm.js was created by Mozilla as a response to Google's Native Client (NaCl) and Portable Native Client (PNaCl), aiming to bring native-speed code to the web. It was a precursor to WebAssembly, which was announced in 2015 and became a W3C recommendation in 2019. WebAssembly provides a portable binary format that is faster to load and execute than asm.js.
