## [OpenAI 模型推翻离散几何中的埃尔德什猜想](https://openai.com/index/model-disproves-discrete-geometry-conjecture/) ⭐️ 9.0/10

OpenAI 的一个模型通过构造一个反例，利用代数数论的方法，推翻了离散几何中一个已有 80 年历史的核心猜想——埃尔德什不同距离问题。 这标志着 AI 驱动数学的一个里程碑，展示了 AI 能够独立解决长期悬而未决的问题，并可能加速纯数学领域的发现。 该模型发现了一个反例，表明对于无穷多个 n 值，n 个点之间单位距离的最大数量超过线性增长率一个固定的正常数，从而推翻了该猜想。证明过程在 Lean 定理证明器中进行了形式化。

## [Mozilla 弃用 asm.js，标志一个时代的结束](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html) ⭐️ 8.0/10

Mozilla 宣布弃用 asm.js（一种能在浏览器中实现接近原生性能的 JavaScript 子集），因为 WebAssembly 已成为高性能 Web 应用的标准。 这标志着一种基础性 Web 技术的终结，该技术为 WebAssembly 铺平了道路，并支持了 Figma 等早期高性能 Web 应用。开发者应将任何剩余的 asm.js 代码迁移到 WebAssembly，以获得更好的性能和未来的兼容性。 asm.js 是 JavaScript 的一个严格子集，允许提前优化，但需要作为 JavaScript 解析，导致包体积更大、加载速度比 WebAssembly 的二进制格式更慢。Mozilla 的 Firefox 是第一个在版本 22 中实现 asm.js 优化的浏览器。

hackernews · eqrion · May 20, 12:01 · [社区讨论](https://news.ycombinator.com/item?id=48206340)

**背景**: asm.js 由 Mozilla 创建，作为对 Google 的 Native Client (NaCl) 和 Portable Native Client (PNaCl) 的回应，旨在将原生速度的代码带到 Web 上。它是 WebAssembly 的前身，WebAssembly 于 2015 年宣布，并于 2019 年成为 W3C 推荐标准。WebAssembly 提供了一种可移植的二进制格式，比 asm.js 加载和执行更快。
