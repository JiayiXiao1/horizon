## [OpenAI 的 Jalapeño 芯片在推理测试中超越英伟达 Blackwell](https://newsletter.semianalysis.com/p/openai-jalapeno-better-than-nvidia) ⭐️ 9.0/10

## [EVE Online 启动从 Stackless Python 2.7 到 Python 3 的期待已久的迁移](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 8.0/10

EVE Online 宣布开始从 Stackless Python 2.7 迁移到 Python 3，使用 futurize 脚本处理 240 万行代码，并手动审查约 2 万个行为差异。该公告于 2026 年 8 月 25 日发布，标志着 16 年来首次重大 Python 升级。 此次迁移意义重大，因为 EVE Online 是生产环境中规模最大、运行时间最长的 Python 代码库之一，其成功将为其他面临类似遗留 Python 2 迁移的组织提供宝贵的案例研究。它也凸显了在升级庞大代码库的同时保持性能和稳定性的挑战，这与更广泛的 Python 社区和大规模软件工程相关。 迁移将使用 futurize 脚本自动将 Python 2 代码转换为 Python 3，然后手动审查约 2 万个 Python 2 和 3 行为不同的地方，例如整数除法（1/2 在 Python 2 中为 0，但在 Python 3 中为 0.5）。公告未说明他们将如何替换 Stackless，但在去年的会议上，他们展示了使用 carbonengine/scheduler 库为他们的新游戏 EVE Frontier 提供的解决方案。

rss · Simon Willison · Aug 25, 22:59

**背景**: EVE Online 自 2003 年推出以来一直运行在 Stackless Python 上，其上一次重大升级是在 2010 年升级到 Stackless Python 2.7。Stackless Python 是 Python 的增强版本，通过称为 tasklet 的微线程提供轻量级并发，但其 GitHub 仓库已于 2025 年 2 月归档，项目已正式停止维护。迁移到 Python 3 是必要的，因为 Python 2 已于 2020 年达到生命周期终点，且 Stackless Python 不再维护，迫使 EVE Online 为其并发需求寻找新的解决方案。
