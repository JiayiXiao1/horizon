## [MicroPython 在 WebAssembly 沙箱中运行 Python](https://simonwillison.net/2026/Jun/6/micropython-in-a-sandbox/#atom-everything) ⭐️ 8.0/10

Simon Willison 发布了 micropython-wasm 的 alpha 版本，这是一个 Python 包，通过 Wasmtime 在 WebAssembly 沙箱中运行 MicroPython 代码，实现了在 Python 应用内安全、隔离地执行 Python 片段。 这解决了 Python 插件系统中长期存在的挑战：安全运行不可信代码而不危及宿主应用。它可能使 Datasette 和 LLM 等工具实现安全的插件执行，并为 AI 代理中的安全代码执行奠定基础。 该沙箱通过 WebAssembly 线性内存和 Wasmtime fuel 预算来强制执行内存和 CPU 限制。它使用自定义的 MicroPython WASI 构件，而非 Emscripten 浏览器构建，并支持通过 PyPI 的二进制 wheel 进行干净安装。

rss · Simon Willison · Jun 6, 03:53

**背景**: WebAssembly (WASM) 是一种为安全、可移植执行而设计的二进制指令格式，常用于浏览器，也可通过 Wasmtime 等运行时在非浏览器环境中使用。MicroPython 是 Python 3 的精简实现，针对微控制器进行了优化。将两者结合，可以在具有硬件级隔离的沙箱中运行 Python 代码。
