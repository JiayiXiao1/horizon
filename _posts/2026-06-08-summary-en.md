## [How Linear Achieves Speed: Local-First & Optimistic Updates](https://performance.dev/how-is-linear-so-fast-a-technical-breakdown) ⭐️ 8.0/10

A technical breakdown explains how Linear achieves its speed through a local-first architecture and optimistic updates, where the client immediately reflects changes locally before syncing with the server. This approach reduces perceived latency from ~300ms to milliseconds, setting a new standard for web application responsiveness and inspiring other projects like Zero and Replicache. Linear uses a sync engine that stores data locally in the browser and applies optimistic updates, then reconciles with the server asynchronously. The trade-off is eventual consistency, which may cause sync lags.

hackernews · howToTestFE · Jun 7, 19:01 · [Discussion](https://news.ycombinator.com/item?id=48437609)

**Background**: Traditional CRUD web apps send requests to a server and wait for a response, incurring round-trip times of hundreds of milliseconds. Local-first architecture moves data and logic to the client, enabling instant UI updates. Optimistic updates assume the server will accept the change, updating the UI immediately without waiting for confirmation.

## [MicroPython in WebAssembly Sandbox for Python](https://simonwillison.net/2026/Jun/6/micropython-in-a-sandbox/#atom-everything) ⭐️ 8.0/10

Simon Willison released micropython-wasm, an alpha Python package that runs MicroPython code in a WebAssembly sandbox using Wasmtime, enabling secure, isolated execution of Python snippets within Python applications. This addresses a long-standing challenge in Python plugin systems: running untrusted code safely without compromising the host application. It could enable secure plugin execution in tools like Datasette and LLM, and provide a foundation for safe code execution in AI agents. The sandbox enforces memory and CPU limits via WebAssembly linear memory and Wasmtime fuel budget. It uses a custom MicroPython WASI artifact, not the Emscripten browser build, and supports clean installation from PyPI with binary wheels.

MicroPython is a lean implementation of Python 3 optimized for microcontrollers. Combining them allows running Python code in a sandbox with hardware-enforced isolation.
