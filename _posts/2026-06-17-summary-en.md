This breakthrough breaks the long-standing foreign monopoly on high-end front-end lithography equipment, significantly advancing China's semiconductor self-sufficiency and potentially reshaping the global chip manufacturing landscape. The machine uses ArF excimer laser (193 nm) with immersion technology to achieve higher resolution, and combined with multiple patterning, it can produce 7nm nodes. **Background**: ArF immersion lithography uses water between the lens and wafer to shorten the effective wavelength of 193 nm light to 132 nm, enabling finer patterning. ## [Stop Using JWTs for Browser Sessions](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

A widely shared GitHub gist argues that JWTs should not be used for browser-based user sessions, citing security flaws and design mismatches. The post has sparked intense debate in the developer community. This debate challenges a common practice in web authentication, potentially influencing how developers choose between JWT and session-based approaches. The outcome could affect security posture for millions of web applications. The gist emphasizes that JWTs are designed for short-lived tokens (e.g., 5 minutes) and are not suitable for longer-lived sessions. Storing JWTs in browser storage (localStorage/sessionStorage) exposes them to XSS attacks, unlike httpOnly cookies.

hackernews · dzonga · Jun 16, 16:49 · [Discussion](https://news.ycombinator.com/item?id=48558147)

**Background**: JSON Web Tokens (JWTs) are a compact, self-contained token format often used for authentication and information exchange. They can be signed and optionally encrypted. Session-based authentication typically uses server-stored session IDs sent via httpOnly cookies, which are not accessible to JavaScript and thus more resistant to XSS.
