## [IETF 提议 HTTP QUERY 方法：带请求体的安全查询](https://httpwg.org/http-extensions/draft-ietf-httpbis-safe-method-w-body.html) ⭐️ 8.0/10

IETF HTTP 工作组正在制定一项草案，新增 HTTP QUERY 方法，允许像 POST 一样在请求体中携带查询条件，同时具备 GET 的安全和幂等特性。 该提案解决了 URI 查询字符串过长的实际限制，允许更复杂的查询而不受长度限制，并改善了 Web API 的缓存、重试和互操作性。 QUERY 方法定义了 Accept-Query 响应头，让服务器声明支持的查询格式（如 application/graphql、application/sql）。当前草案仍在讨论中，将于 2026 年 12 月到期。

telegram · zaihuapd · Jun 20, 06:28

**背景**: HTTP GET 请求安全且幂等，但不能携带请求体，导致复杂查询必须放入 URI 中，而 URI 有长度限制。POST 请求可以携带请求体，但不安全也不幂等，使得缓存和重试变得困难。QUERY 方法结合了两者的优点。
