## [Freenet Redesign: Decentralized KV Store with WebAssembly Contracts](https://freenet.org/) ⭐️ 8.0/10

A ground-up redesign of Freenet has been launched as a global decentralized key-value store where keys are WebAssembly contracts that define valid state, mutation rules, and synchronization logic. Early applications include River (decentralized group chat) and Delta (decentralized CMS), with users already building games and other apps. This redesign introduces a novel approach to consistency in decentralized systems by requiring each contract to define a commutative merge operation, enabling state updates to spread like a virus and achieve global consistency in seconds. It could lower the barrier for building decentralized apps by allowing them to run in a browser while interacting with the P2P network locally. Freenet uses a unique delta-sync mechanism for efficient state synchronization, and applications are downloaded from the network and run as single-page apps in a browser, connecting to the local Freenet peer via WebSocket. The project has been running since December 2024 and provides installers for major desktop OSs, with mobile support not yet available.

hackernews · sanity · May 21, 14:34 · [Discussion](https://news.ycombinator.com/item?id=48223362)

**Background**: Freenet is a peer-to-peer platform originally created in the early 2000s for censorship-resistant communication and file sharing. The new version is a complete rewrite, now renamed from the original Freenet (which continues as Hyphanet). It leverages WebAssembly to allow flexible, user-defined consistency models via contracts, and uses a commutative merge operation inspired by CRDTs (Conflict-free Replicated Data Types) to achieve strong eventual consistency.
