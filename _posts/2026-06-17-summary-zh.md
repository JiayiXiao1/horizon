## [停止在浏览器会话中使用 JWT](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

一篇广泛传播的 GitHub gist 文章指出，JWT 不应用于基于浏览器的用户会话，并列举了安全缺陷和设计不匹配的问题。该帖子在开发者社区引发了激烈讨论。 这场辩论挑战了 Web 身份验证中的常见做法，可能影响开发者在 JWT 和基于会话的方法之间的选择。其结果可能影响数百万 Web 应用的安全态势。 该 gist 强调 JWT 是为短生命周期令牌（例如 5 分钟）设计的，不适合较长时间的会话。将 JWT 存储在浏览器存储（localStorage/sessionStorage）中会使其暴露于 XSS 攻击，而 httpOnly cookie 则没有此问题。

hackernews · dzonga · Jun 16, 16:49 · [社区讨论](https://news.ycombinator.com/item?id=48558147)

**背景**: JSON Web Token（JWT）是一种紧凑、自包含的令牌格式，常用于身份验证和信息交换。它们可以被签名并可选择加密。基于会话的身份验证通常使用通过 httpOnly cookie 发送的服务器存储的会话 ID，这些 cookie 无法被 JavaScript 访问，因此更能抵抗 XSS 攻击。

## [生成式 AI 市场分化，ChatGPT 份额下滑](https://t.me/zaihuapd/41991) ⭐️ 7.0/10
