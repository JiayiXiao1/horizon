This outage highlights the fragility of global CDN and WAF infrastructure when deploying emergency security patches, and underscores the cascading impact of a single rule update on a large portion of the internet. It also raises concerns about the reliance on legacy proxy architectures (FL1) and the need for more rigorous testing of WAF rule changes. The outage lasted from 08:47 to 09:12 UTC, and full recovery was achieved by 09:12. The faulty WAF rule was part of a managed ruleset update targeting CVE-2025-55182, which affects React Server Components (RSC) in Next.js applications. Only customers on the legacy FL1 proxy were affected; those on newer proxy architectures were not impacted.

Its Web Application Firewall (WAF) uses managed rulesets to block malicious requests. The legacy FL1 proxy is an older version of Cloudflare's proxy infrastructure. CVE-2025-55182, also known as React2Shell, is a critical unauthenticated remote code execution vulnerability in React Server Components, which Next.js relies on for server-side rendering.
