## [Zeroserve：可用 eBPF 脚本的零配置 Web 服务器](https://su3.io/posts/introducing-zeroserve) ⭐️ 8.0/10

Zeroserve 是一款新型零配置 HTTPS 服务器，使用 eBPF 进行脚本编写，旨在以更灵活的方式替代 nginx 和 Caddy。它通过 HTTP/2 和 TLS 1.3 提供网站服务，支持热重载，并允许用户用 C 语言编写 eBPF 程序来自定义请求处理。 该项目通过提供零配置、可脚本化的替代方案，并利用 eBPF 实现高性能和安全性，挑战了 nginx 和 Caddy 等传统 Web 服务器的主导地位。它可能简化 Web 服务器部署，并允许在内核中直接进行更动态、可编程的请求处理。 Zeroserve 使用 Rust 编写，目前是单线程的，但作者指出通过 SO_REUSEPORT 实现 fork 很容易添加。它使用 eBPF 进行脚本编写，用户编写 C 程序，由内核的 eBPF 验证器进行安全检查，而不是使用声明式配置语言。

hackernews · losfair · Jun 6, 14:59 · [社区讨论](https://news.ycombinator.com/item?id=48425723)

**背景**: eBPF（扩展的伯克利数据包过滤器）是一种 Linux 内核技术，允许在内核空间安全高效地执行用户定义的程序，常用于网络、可观测性和安全领域。传统的 Web 服务器如 nginx 和 Caddy 使用声明式配置文件（例如 location 块、重写规则）来定义行为，这可能会变得复杂。Zeroserve 用 eBPF 程序取代了这种方式，这些程序可以在底层检查和修改请求，从而可能提供更高的灵活性和性能。
